🔍 ¿Dónde se Guardan tus Registros?

📍 Ubicación: LocalStorage del Navegador

Los datos se guardan en el almacenamiento local de tu navegador web.

Clave de almacenamiento: Productos_data

🧪 Prueba en Vivo

Paso 1: Agrega algunos datos de prueba

Paso 2: Ver los datos guardados

Paso 3: Contar registros

Paso 4: Abrir Herramientas del Desarrollador

Paso 5: Limpiar datos (opcional)

💡 TIP: Presiona F12 para abrir las Herramientas del Desarrollador, luego ve a Application → Local Storage → file:/// para ver tus datos guardados.
